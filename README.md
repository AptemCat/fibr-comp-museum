# ByteMuseum

*Гордеев Артём Александрович ЭФБО-02-25*

Сайт музея компьютеров, вычислительных устройств и цифровых технологий с использованием Bootstrap.

## Планируемые страницы

- **Главная** - краткое описание музея, популярные экспонаты, преимущества
- **Экспозиции** - список постоянных и временных выставок по эпохам и направлениям с карточками экспонатов
- **Экспонат** - подробная информация об отдельном экспонате: описание, история и характеристики
- **Посетителям** - режим работы, стоимость билетов, правила посещения и FAQ
- **Запись на экскурсию** - форма для выбора экскурсии и отправки заявки

## Реализовано

### Практическая работа №9

Главная страница с описанием музея, преимуществами и тремя популярными экспонатами.

- Адаптивная Bootstrap-сетка: главный блок перестраивается из одной колонки в две, экспонаты - из одной в две и три.
- Закреплённая шапка (`sticky-top`), якорная навигация и фиксированная ссылка "Наверх".
- Отступы при переходе к якорям, чтобы шапка не перекрывала заголовки.
- Локальные SVG-иллюстрации, адаптивные изображения и отложенная загрузка изображений экспонатов.
- Цветовая тема в зелёных тонах.
- CSS-переменные, БЭМ-классы собственных блоков, состояния ссылок и кнопок, заметный клавиатурный фокус.

## Технологии

HTML5, CSS3 и Bootstrap 5.3.8. Bootstrap подключён через CDN jsDelivr, собственный `css/custom.css` - после Bootstrap. Для загрузки Bootstrap требуется интернет.

Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `col-lg-6`, адаптивные gutters, Flexbox-утилиты, классы отступов, кнопки `btn` и утилиты позиционирования.
