# ByteMuseum

*Гордеев Артём Александрович ЭФБО-02-25*

Сайт музея компьютеров, вычислительных устройств и цифровых технологий с использованием Bootstrap.

## Страницы

- **Главная** - краткое описание музея, популярные экспонаты, преимущества
- **Экспозиции** - список постоянных и временных выставок по эпохам и направлениям с карточками экспонатов
- **Экспонат** - подробная информация об отдельном экспонате: описание, история и характеристики
- **Посетителям** - режим работы, стоимость билетов, правила посещения и FAQ
- **Запись на экскурсию** - форма для выбора экскурсии и отправки заявки

## Реализовано

### Практическая работа №9

Главная страница с описанием музея, преимуществами и тремя популярными экспонатами.

- Адаптивная Bootstrap-сетка: главный блок перестраивается из одной колонки в две, экспонаты - из одной в две и три.
- Закреплённая шапка (`sticky-top`), якорная навигация и фиксированная ссылка "Наверх".
- Отступы при переходе к якорям, чтобы шапка не перекрывала заголовки.
- Локальные SVG-иллюстрации, адаптивные изображения и отложенная загрузка изображений экспонатов.
- Цветовая тема в зелёных тонах.
- CSS-переменные, БЭМ-классы собственных блоков, состояния ссылок и кнопок, заметный клавиатурный фокус.

### Практическая работа №10

Многостраничный сайт дополнен готовыми компонентами Bootstrap и формой записи на экскурсию.

- Общая навигация `navbar` с раскрывающимся мобильным меню (`collapse`) и выделением текущей страницы.
- Страница `exhibitions.html` с девятью экспонатами: карточки `card`, кнопки `btn`, метки постоянных и временных экспозиций `badge`.
- Единая страница экспоната `exhibit.html?id=...`.
- Хлебные крошки `breadcrumb`, якорные переходы и адаптивные таблицы `table` / `table-responsive`.
- Страница `visitors.html`: стоимость билетов, правила посещения, FAQ на `accordion`, информационное сообщение `alert`, адрес, телефон, время работы и встроенные Яндекс Карты.
- Страница `tours.html`: выбор одной из трёх экскурсий, даты, времени и числа участников, контактные данные и комментарий. Используются `form-control`, `form-select`, `input-group` и `form-check`.
- Проверка обязательных полей, имени, электронной почты и телефона. Запись доступна со следующего дня, кроме понедельников; размер группы - от 1 до 20 человек. Ошибки сопровождаются подсказками и переводом фокуса на первое некорректное поле.
- После корректного заполнения открывается `modal` с просмотром результата заявки. Можно вернуться к форме без потери введённых данных или очистить её отдельной кнопкой.
- Логотип и название в шапке, favicon, расширенный футер с описанием сайта, контактами, адресом и копирайтом.
- Для новых экспонатов добавлены иллюстрации.

## Технологии

HTML5, CSS3, JavaScript и Bootstrap 5.3.8. Bootstrap CSS и JS Bundle подключены через CDN jsDelivr, собственный `css/custom.css` - после Bootstrap. Для загрузки Bootstrap требуется интернет.

Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `col-lg-6`, адаптивные gutters, Flexbox-утилиты, классы отступов, кнопки `btn` и утилиты позиционирования.

Bootstrap-компоненты: `navbar`, `collapse`, `card`, `badge`, `breadcrumb`, `alert`, `accordion`, `modal`, `table`, `form-control`, `form-select`, `input-group`, `form-check`.
