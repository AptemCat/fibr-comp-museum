# ByteMuseum

*Гордеев Артём Александрович ЭФБО-02-25*

Сайт музея компьютеров, вычислительных устройств и цифровых технологий с использованием Bootstrap.

## Планируемые страницы

- **Главная** - краткое описание музея, популярные экспонаты, преимущества
- **Экспозиции** - список постоянных и временных выставок по эпохам и направлениям с карточками экспонатов
- **Экспонат** - подробная информация об отдельном экспонате: описание, история и характеристики
- **Посетителям** - режим работы, стоимость билетов, правила посещения и FAQ
- **Запись на экскурсию** - форма для выбора экскурсии и отправки заявки
